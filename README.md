# 伟哥应用商店

自己家里用的电视应用商店。无广告、无推荐位、点一下直接装。
TV 端是一个原生 APK，服务端在你家电脑上跑，所有请求走局域网。

```
┌─────────────┐   局域网     ┌──────────────┐   HTTPS   ┌──────────┐
│ 电视 / 盒子 │ ──────────► │  服务端(Python)│ ────────► │ 当贝市场 │
│  客户端 APK │ ◄────────── │  索引+图标+APK │ ◄──────── │  网页版  │
└─────────────┘             └──────────────┘           └──────────┘
```

## 为什么这么干

- 上游只有网页版没有开放 API，但列表页和 APK 直链都能抓，服务端替你把脏活干了
- TV 只跟局域网通信，图标和 APK 都本地缓存 —— 翻页不卡，同一个应用第二次秒装
- 上游哪天改版或失效，只改 `source_dangbei.py`，不用重装客户端

## 跑起来

1. 双击 `启动服务.bat`（或 `python server.py`）
2. 启动后会自动抓一遍索引，控制台会打印每类抓了多少条，约 1 分钟
3. 看浏览器打印的地址，比如 `http://192.168.8.9:8018/`
4. TV 装 `伟哥应用商店-v1.0.apk`，打开后自动发现服务器，不用配 IP

装 APK 到电视：

```bash
# 你的盒子 IP 换成实际的
adb connect 192.168.8.159:5555
adb install -r "伟哥应用商店-v1.0.apk"
```

或者拷到 U 盘，用电视自带的文件管理装。

**首次安装会要你允许「安装未知应用」**，允许一次就行，之后一路点安装。

## 遥控器操作

| 键 | 作用 |
|---|---|
| 方向键 | 移动焦点 |
| OK | 打开详情 / 安装 |
| MENU（三条杠那个） | 菜单：搜索、换服务器、重新查找 |
| BACK | 搜索页返回到分类 |

## 目录

```
cleanstore/
├── server.py            服务端（零第三方依赖）
├── source_dangbei.py    数据源：抓列表 / 搜索 / APK 直链
├── apkmeta.py           解析 APK 的包名版本图标（下载后补库用）
├── web/index.html       手机/电脑也能用的网页版商店
├── data/
│   ├── store.db         索引库
│   ├── apks/            已经下载过的 APK（缓存）
│   └── icons/           图标缓存
├── app/                 TV 客户端源码
│   ├── build.sh         打包脚本（aapt2 + javac + d8，不用 gradle）
│   └── 伟哥应用商店-v1.0.apk
└── 启动服务.bat
```

## 接口

```
GET  /api/home?cat=影音&n=200   列表（cat: 全部/影音/工具/生活/游戏/新上架）
GET  /api/search?q=关键词        搜索（本地命中不够会实时上游搜）
GET  /api/app/<id>              单个详情
GET  /icon/<id>                 图标（本地缓存）
GET  /dl/<id>                   APK（首次中转并落盘，支持 Range）
POST /api/rebuild               重建索引
UDP  :8019                      自动发现（收到 CLEANSTORE_DISCOVER 回端口）
```

## 已知情况

- 上游每个分类只有 5 页 50 条，16 个分类去重后约 700~800 个应用；搜不到的应用直接搜关键词，搜索能覆盖全库
- 应用是否「已安装」靠包名判断，包名要等第一次下载后由 `apkmeta.py` 解析补进库，所以新应用首次只显示「安装」
- 端口 8018 被占用的话 `python server.py --port 8020`，客户端菜单里手动填地址

## 换成 NAS / 软路由跑

把整个目录拷过去，`python3 server.py` 即可（纯标准库，Python 3.8+）。
常驻可以用 systemd 或 nohup，记得放行 8018 和 UDP 8019。
aapt2 找不到时会退回纯 Python 解析，包名版本照样能取，图标退化为 APK 内最大的 png。
